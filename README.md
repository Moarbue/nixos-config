# nixos-config

NixOS flake for my desktop and laptop: [niri](https://github.com/niri-wm/niri) as the compositor,
[home-manager](https://github.com/nix-community/home-manager) for the user environment and
[noctalia](https://github.com/noctalia-dev/noctalia) as the shell.

## Hosts

| Host     | Machine                                 | Notes                                         |
| -------- | --------------------------------------- | --------------------------------------------- |
| `moarpc` | Desktop PC (AMD CPU, GTX 970, Btrfs)    | legacy NVIDIA 580 driver, Steam, gaming       |
| `moarlt` | ThinkPad X13 Gen 3 (AMD CPU, Radeon)    | LUKS, hibernation, power-profiles-daemon, fwupd |

## Layout

```
flake.nix                    # mkHost helper → nixosConfigurations.{moarpc,moarlt}
modules/nixos/               # shared NixOS modules
  base.nix                   #   nix settings, locale, networking, audio, bluetooth
  btrfs.nix                  #   subvolume mount options, scrub, trim
  users.nix                  #   user account and shell
  desktop.nix                #   niri, greetd/tuigreet, fonts, portals
  gaming.nix                 #   Steam, gamemode (desktop only)
  laptop.nix                 #   power management, fwupd (laptop only)
  hibernate.nix              #   swapfile + suspend-then-hibernate (laptop only)
  snapshots.nix              #   snapper timeline snapshots of / and /home
hosts/<name>/
  default.nix                # host-specific NixOS config
  hardware-configuration.nix # generated by nixos-generate-config
  home.nix                   # per-host home-manager overrides
  nvidia.nix                 # (moarpc only)
home/moarbue/                # shared home-manager config
  options.nix                #   my.font.*, my.niri.* — the per-machine knobs
  niri.nix, niri/base.kdl    #   niri config: generated part + static part
  programs/*.nix             #   alacritty, git, librewolf, noctalia, opencode, shell, ssh, vim
```

Machine differences are kept small: shared modules read the `my.*` options from
`home/moarbue/options.nix`, and each host sets them in `hosts/<name>/home.nix`.
The niri config is assembled in `home/moarbue/niri.nix` and validated with `niri validate`
at build time.

## Usage

Hostnames match the flake output names:

```sh
sudo nixos-rebuild switch --flake .#$(hostname)   # apply
nixos-rebuild build --flake .#moarpc              # build without activating
nix flake update                                  # update all inputs
nix flake check                                   # evaluate everything
```

New host: add `hosts/<name>/{default,home}.nix` and register the name in `flake.nix`.

## Manual steps (not managed by Nix)

- **SSH key**: one per device, never stored in this repo.
  `ssh-keygen -t ed25519 -C "moarbue@$(hostname)"`, then add the public key on GitHub.
- **opencode**: `opencode auth login` once per machine.
- **Monitors**: check output names and scale with `niri msg outputs` and adjust `my.niri.outputs`
  in `hosts/<name>/home.nix`.
- **Snapshots**: `sudo btrfs subvolume create /.snapshots /home/.snapshots` once per machine before the first switch.
